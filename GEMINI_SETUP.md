# Setting Up Google Gemini AI for Narration Generation

## Quick Setup Guide

### 1. Get Your Gemini API Key

1. Visit [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click **"Get API Key"** or **"Create API Key"**
4. Copy your API key

### 2. Configure the Application

1. Open the `.env.local` file in the project root
2. Replace `your_gemini_api_key_here` with your actual API key:

```env
GEMINI_API_KEY=AIzaSy...your_actual_key_here
```

3. Save the file

### 3. Restart the Development Server

If the server is running, restart it to load the new environment variable:

```bash
# Stop the server (Ctrl+C)
# Then restart:
npm run dev
```

### 4. Test the AI Generation

1. Open http://localhost:3000
2. Create a new project and add a step
3. Click the **"AI Generate"** button (magic wand icon)
4. The narration should now be generated by Gemini AI!

## Features

- **Smart Narration**: Gemini generates contextual, professional narration based on your step title and action
- **Automatic Fallback**: If the API key isn't configured or there's an error, it falls back to template-based generation
- **Error Handling**: Graceful error handling ensures the app keeps working even if the API fails

## Troubleshooting

### "Using template-based narration" warning

This means your API key isn't configured. Check:
- Is the `.env.local` file in the project root?
- Did you replace `your_gemini_api_key_here` with your actual key?
- Did you restart the dev server after adding the key?

### API errors

- Check your API key is valid
- Ensure you have API quota remaining (Gemini has a free tier)
- Check your internet connection

## API Limits

Google Gemini offers a generous free tier:
- **Free tier**: 60 requests per minute
- **Cost**: Free for moderate usage

For production use, consider upgrading to a paid plan if needed.

## Security Note

⚠️ **Never commit your `.env.local` file to Git!**

The `.env.local` file is already in `.gitignore` to prevent accidental commits of your API key.
